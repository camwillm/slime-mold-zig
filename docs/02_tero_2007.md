# Tero, Kobayashi, Nakagaki (2007) — J. Theor. Biol. 244:553
## "Mathematical model for adaptive transport network"

### Core equations — implement exactly

Flow (Poiseuille):
  Q_ij = D_ij * (P_i - P_j) / L_ij

Pressure conservation at each node:
  Sum of Q_ij for all neighbors j = 0  (interior nodes)
  Sum of Q_ij = +I_0  (food source nodes)
  Sum of Q_ij = -I_0  (sink nodes)

Tube adaptation:
  dD_ij/dt = |Q_ij|^mu - decay * D_ij
  mu = 1.0, decay = 0.01

### mu parameter
mu < 1: tree network (no loops)
mu = 1: shortest path (our target)
mu > 1: fault tolerant redundant paths

### Critical rule
This is NOT a particle simulation.
There are no agents. The network IS the organism.
Each edge has conductance. Each node has pressure.
That is the entire model.

### Gauss-Seidel pressure update
P_i = Sum(D_ij * P_j) / Sum(D_ij)  for interior nodes
Run 25 iterations per tick.
