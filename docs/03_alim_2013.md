# Alim, Amselem, Peaudecerf, Brenner, Pringle (2013) — PNAS 110:13306
## "Random network peristalsis in Physarum polycephalum"

### Key finding
Physarum uses PERISTALSIS to drive cytoplasmic flow.
Tube walls contract rhythmically in a traveling wave pattern.

### Measurements
Oscillation period: ~100 seconds
Phase gradient: linear, 0 to 2π across entire organism
Wavelength adapts to organism size (self-tuning)

### Peristaltic wave equation
φ(x, t) = ωt + kx
ω = 2π/100 (angular frequency)
k = wave number (adapts to size)

Effective tube conductance:
D_eff = D * (1 + A * sin(φ))
A = contraction amplitude = 0.3

### Phase coupling (Kuramoto model)
dφ_i/dt = ω + K * Sum sin(φ_j - φ_i)
K = 0.1

### Rules for simulation
1. Each tube stores phase φ
2. Phase advances by ω each tick
3. Adjacent tubes couple phases
4. D_eff = D * (1 + A * sin(φ))
5. Net flow follows phase gradient

### Visual result
Visible pulsing along tubes — bright spot travels along tube.
Period ~100 ticks = 100 second biological time.
